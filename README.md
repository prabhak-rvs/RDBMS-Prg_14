PL/SQL: Sum of Two Numbers
Problem
Write an anonymous PL/SQL block that:
1.	Declares two numeric variables.
2.	Assigns the values 10 and 20 to the variables.
3.	Calculates their sum.
4.	Displays the sum using DBMS_OUTPUT.PUT_LINE.
Expected output
Sum = 30

Requirements
•	Use a PL/SQL anonymous block.
•	Declare two variables for the numbers.
•	Display the result with DBMS_OUTPUT.PUT_LINE.
•	Do not use input or database tables.
